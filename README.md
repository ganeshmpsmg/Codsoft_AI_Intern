# Rule-Based Chatbot 🤖   Codsoft_AI-Internship

This project is a **Rule-Based Chatbot built using Python** as part of the **CodSoft AI Internship - Task 1**.

The chatbot interacts with users by matching input patterns and responding with predefined answers using **regular expressions (regex)**.

---

## 🚀 Features

- Greets users with multiple greeting patterns
- Responds to common questions
- Tells jokes
- Displays current **time and date**
- Responds to emotions (happy/sad)
- Handles unknown inputs with fallback responses
- Simple terminal-based chatbot interaction

---

## 🧠 Technologies Used

- Python
- Regular Expressions (`re`)
- Random module
- Datetime module
